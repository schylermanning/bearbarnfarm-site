# Bear Barn Farm site

The static site for bearbarnfarm.com: a home page and /privacy/ for the Bear Barn Farm Etsy shop. It is not a store.

| File | What it is |
| --- | --- |
| `index.html` | Home page |
| `privacy/index.html` | Privacy policy, at `/privacy/` |
| `logo.jpg` | Shop logo |
| `CNAME` | Custom domain; don't delete |
| `.nojekyll` | Serves the files as they are |

To update the site, edit the files, commit and push to `main`.
